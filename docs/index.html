SystemLens

Architecture context, kept local.

SystemLens gives coding agents source-evidenced Java/Spring architecture context before they change a system. It indexes REST, Kafka, build modules, OpenAPI, MongoDB, and explicit architecture facts into a local SQLite snapshot.

Open the simple model Explore the supermarket model View on GitHub

Quick start

At the root of a Java/Spring repository, run systemlens init, systemlens doctor, and systemlens index. Use systemlens mcp for an agent workflow, or export an interactive graph with systemlens export microservices --html architecture.html.
